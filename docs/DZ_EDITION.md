# Golana DZ Edition

Custom firmware for the M-VAVE FM-1.

Based on Golana by Gadlele and Felucca.

## DZ features

- 64-step sequencer
- 32 program slots (up to 2,048 steps)
- Song mode with FIRST / LAST selection
- ONCE and REPEAT playback
- USB MIDI output
- Extended step and program storage
- Web emulator support

## Hardware status

Tested on a real M-VAVE FM-1:
- 64-step sequencing
- Song mode playback
- USB MIDI output
- MIDI song import and playback

## Current limitations

- One stored note per sequencer step
- Song mode plays consecutive program slots
- Not a full General MIDI file player
